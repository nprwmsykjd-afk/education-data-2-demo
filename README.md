# Система сбора данных 2.0

Интерактивный прототип развития действующей ведомственной системы сбора данных для подведомственных организаций Министерства образования и науки ЛНР.

При открытии сайта показ начинается автоматически. В ходе показа можно выполнить основные действия: согласовать связь двух по-разному названных полей с одним показателем, опубликовать форму, отправить и принять учебный отчет, посмотреть паспорт организации и свод, изучить реорганизацию. После показа доступен свободный режим.

## Что демонстрирует проект

- Один показатель имеет постоянный код, определение, единицу измерения и период. Похожее название поля только предлагает соответствие; специалист проверяет смысл и утверждает связь.
- Ранее принятое постоянное значение предлагается школе для подтверждения. Значение за прошлый месяц не считается значением за новый месяц.
- Принятый отчет попадает в паспорт учреждения и свод, где видны непредставленные сведения.
- При реорганизации сохраняются история отчетов и связь с правопреемником по ID организации.

**Все организации и числа условные.** Это демонстрация сценария, а не промышленный сервис. Переключение ролей в показе не является авторизацией. Связи с действующей системой и ТОР «Моя школа» сейчас нет. Данные свободного режима хранятся в браузере посетителя и сбрасываются при повторном открытии.

## Перед пилотом

Нужны перечень реальных форм и утвержденные определения показателей, проверка с пользователями, замеры времени и ошибок, проверка прав доступа, журнал действий и резервное копирование. Решение о будущей интеграции принимается после оценки интерфейсов и состава данных источника.
