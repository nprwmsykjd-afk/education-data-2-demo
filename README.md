# Система сбора данных 2.0

Демонстрационный прототип развития системы МОН ЛНР. Все организации и значения условные. Переключатель ролей — сценарий показа, а не производственная аутентификация. Проект не подключён к действующей системе и ТОР «Моя школа».

## Показ

При каждом открытии восстанавливаются учебные данные и автоматически начинается показ. Пройдите 22 шага кнопкой «Продолжить». Нажимайте выделенные кнопки на экранах системы: утвердите связи показателей, опубликуйте форму, заполните и подтвердите поля школы, отправьте отчёт, откройте строку школы на проверке и примите конкретный отчёт. После каждого действия проверьте изменившееся значение или статус. В конце сравните прошлую и новую недели, затем два учебных года. После последнего экрана появится кнопка перехода в свободный режим. «Повторить показ» восстанавливает исходные учебные данные.

## Автономный файл

После сборки сайта `node scripts/build-offline.mjs` создаёт `offline-dist/index.html`: самостоятельный HTML без внешних зависимостей. Извлеките ZIP на другом ПК и откройте файл двойным щелчком без сервера или интернета. Изменения свободного режима действуют до следующего открытия файла либо до повтора показа; с онлайн-версией данные не синхронизируются.

## Правила

Принятие отчёта — граница включения данных в витрину. Агрегаты используют сведения выбранного периода и показывают охват. Месячные итоги не переносятся в следующий месяц. Неоднозначный столбец нельзя связать автоматически. ID организации сохраняется при переименовании; прежние отчёты остаются за прежней организацией при реорганизации.

## Дальнейшее внедрение

Для реального использования нужны обследование структуры действующей системы, согласование определений показателей и видов отчётности, рабочая модель пользователей и прав, журнал действий, резервное копирование и испытания. Обмен с ТОР «Моя школа» зависит от доступного состава данных и согласованных интерфейсов. Прототип не подтверждает реальную экономию времени — это измеряется в пилоте.
